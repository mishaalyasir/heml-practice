Registration Form

A simple and beginner-friendly Registration Form created using HTML.
This project is made for practicing different HTML form elements and input types.

Features
User registration form
Required field validation
Text and password inputs
Email and number fields
Checkboxes for education selection
Radio buttons for course selection
Date and time picker
File upload option
Dropdown menu
Color picker
Range slider for experience level
Technologies Used
HTML5
Form Fields

The form contains the following fields:

Applicant Name
Father Name
Password
Email Address
Phone Number
Education Selection
Date & Time Selection
Document Upload
Day Selection
Uniform Color Picker
Course Selection
Experience Level
Purpose of the Project

The purpose of this project is to practice:

HTML forms
Different input types
Form structure
Basic validation using required
User input handling
How to Run the Project
Download or clone the project files.
Open the project folder.
Run the index.html file in any browser.

If you are using VS Code:

Open the project in VS Code.
Install the Live Server extension.
Right click on index.html.
Click Open with Live Server.
